Admin Capabilities — Act on Behalf of Employees

Admin can register employees directly, view any employee's leave details, and submit leave requests on their behalf

Admin Panel
🛡
Admin Superset Principle
Admin can do everything a front-end user (Employee / Manager) can do, plus more. This includes: registering employees without the Gmail OAuth self-service flow, viewing the complete leave history and balance of any employee, and submitting leave requests on behalf of any employee. All admin actions on behalf of employees are recorded in the audit log with the acting admin's identity.
➕
1. Add Employee Directly
Admin fills the full employee profile form in the admin panel. No Gmail OAuth self-registration needed. Employee receives a welcome email and can log in via Gmail.
Admin Panel → Employees → Add Employee
👁
2. View Employee Leave Details
Admin can open any employee's profile and see their full leave balance, leave history, pending requests, and approval timeline — exactly as the employee sees it.
Admin Panel → Employees → [Name] → Leave
📤
3. Submit Leave on Behalf
Admin can submit a leave request for any employee. The request goes through the normal workflow. Audit log records "submitted by [Admin Name] on behalf of [Employee Name]".
Admin Panel → Employees → [Name] → Apply Leave

📈 CL & SL Accrual Logic (Post-Probation)
Rate: 0.5 days CL + 0.5 days SL per month
Full year (12 months)CL = 6, SL = 6
Month Counting Rule:
On/before 15th: That month counts as a full month
e.g. Probation ends Mar 10 → Mar counts → 10 months (Mar–Dec)
After 15th: That month does NOT count — starts next month
e.g. Probation ends Mar 20 → Apr starts → 9 months (Apr–Dec)
Accrual Examples:

Rounding Rule: Accrual is tracked in 0.5-day increments. No further rounding — 4.5 is stored and displayed as 4.5. Admin can view and manually adjust at year-end.
