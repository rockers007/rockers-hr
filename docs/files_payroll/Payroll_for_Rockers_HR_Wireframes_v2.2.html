CORRECTION 1 — CLARIFIED
PF — Conditional Fixed Amount (NOT a percentage on cap)
💡
Exact Rule from HRBhrugisha V:
IF Basic ≥ ₹15,000 → Employee PF = ₹1,800 fixed (not 12% of ₹15,000)
IF Basic < ₹15,000 → Employee PF = 12% × Actual Basic
Same rule applies to Employer PF. NestJS code: basic >= 15000 ? 1800 : Math.round(basic * 0.12)
❌ PREVIOUS (Wrong)
✗
PF = 12% of Actual Basic
e.g. Basic ₹33,908 → PF = ₹4,069
✅ CORRECT (from sample data)
✓
IF Basic ≥ ₹15,000 → PF = ₹1,800 (fixed amount)
IF Basic < ₹15,000 → PF = 12% × Basic
e.g. Basic ₹33,908 ≥ ₹15,000 → PF = ₹1,800 fixed
Rule: Per EPFO statutory limit, PF contributions (employee and employer) are capped at a basic wage of ₹15,000/month.
If Basic < ₹15,000 → PF = 12% × Basic | If Basic ≥ ₹15,000 → PF = 12% × ₹15,000 = ₹1,800 (fixed maximum)
Verified: PQR: Basic ₹33,908 ≥ ₹15,000 → ₹1,800 fixed ✓ | HSBC: Basic ₹12,500 < ₹15,000 → 12%×₹12,500 = ₹1,500 ✓ | Reliance: Basic ₹12,000 → 12%×₹12,000 = ₹1,440 ✓

CTC Formula — Employer PF included, Employee PF is only deduction
❌ PREVIOUS (Wrong)
✗

CORRECTION 3
OT Rate Formula — Based on GROSS (not CTC)
❌
Previous: OT = CTC ÷ 12 ÷ 30 ÷ 9 × 1.5
✅
Correct: OT = Gross ÷ 30 ÷ 9 × 1.5 (confirmed by client)
Per Day = Gross ÷ 30
Per Hour = Per Day ÷ 9
OT Rate = Per Hour × 1.5
Example RT-DEV-153: ₹38,200 ÷ 30 ÷ 9 × 1.5 = ₹212.22/hr OT rate
NEW DETAIL 4
LWP — "Salary for Calculation" Column — Components Calculated AFTER Deduction
From the salary sheet: there is a "Salary for Calculation" column = Gross - LWP Amount Deduction.
All 7 percentage components (Basic, HRA, etc.) are calculated on Salary for Calculation, not raw Gross.
LWP Amount = (Gross ÷ 30) × LWP Days | Salary for Calc = Gross − LWP Amount
Example: Gross ₹38,200, LWP 2 days → LWP Deduct = ₹38,200÷30×2 = ₹2,547
Salary for Calc = ₹38,200 − ₹2,547 = ₹35,653
Basic = 50% of ₹35,653 = ₹17,826 (NOT 50% of ₹38,200)
